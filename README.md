# Heeler

Downloads, release notes, and the update manifest for Heeler, the node-based RAW photo editor from Vagabond Burro, plus community extras: example scripts, node presets, and controller configs. Heeler is proprietary; this repository holds no source.

## Download

The current release is on the [Releases](https://github.com/vagabond-burro/heeler/releases/latest) page. Each release carries the installer for every platform and the `latest.json` manifest the app reads for **Help > Check for Updates**.

Heeler is bought inside the app. Documentation, pricing, and the user guide live at [www.heeler.app](https://www.heeler.app).

## What is here

| Folder | Contents | License |
| --- | --- | --- |
| [`scripts/`](scripts/) | Example Python scripts for Heeler's built-in console and batch runner | MIT |
| [`presets/`](presets/) | Shareable looks as `.heelerpreset` files | CC0 |
| [`controllers/`](controllers/) | Profiles for hardware controllers such as TourBox | CC0 |
| [`docs/`](docs/) | How releases and the update manifest are laid out | CC0 |

The installers on the Releases page are covered by the [Heeler EULA](https://www.heeler.app/docs/legal/eula/), not by the licenses above. See [LICENSE](LICENSE) for the exact split.
