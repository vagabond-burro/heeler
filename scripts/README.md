# Scripts

Example Python scripts for Heeler. Each uses only the public `heeler` package and Python's standard library, and says at the top whether it runs in the app's console, the batch runner, or both.

Open a script in the console with **Open**, or run it with the batch runner; see the scripting section of the [user guide](https://www.heeler.app) for both.

| Script | Runs in | What it does |
| --- | --- | --- |
| [promote_picks.py](promote_picks.py) | app or batch | Rates every pick five stars and clears the rating on every reject |
