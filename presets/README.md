# Presets

Shareable looks as `.heelerpreset` files, exported from Heeler's Presets tab with **Export** and imported with **Import**. A preset file is YAML, the same format as node recipe files, so you can read and edit one in any text editor; [Preset files](../docs/user-guide/presets.md#preset-files) in the user guide explains the fields. Presets exported before Heeler 2026.5.3 are JSON, and still import. A look carries Develop decisions (exposure, color, curves, detail) and leaves the photograph's crop, layers, masks, and Finish stack alone, so it applies cleanly to any photograph.

Each subfolder is a category. Its README lists the looks inside and what each is for.
