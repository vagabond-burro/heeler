# Presets

Shareable looks as `.heelerpreset` files, exported from Heeler's Presets tab with **Export** and imported with **Import**. A look carries Develop decisions (exposure, color, curves, detail) and leaves the photograph's crop, layers, masks, and Finish stack alone, so it applies cleanly to any photograph.

Each subfolder is a category. Its README lists the looks inside and what each is for.
